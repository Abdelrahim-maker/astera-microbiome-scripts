# Original denoising and amplicon-processing scripts

The five scripts at this folder root were copied unchanged from OSC 000_scripts. related_originals/ contains other amplicon import, ASV, taxonomy and postprocessing scripts found beside them. Copies are archival source files, not a newly validated executable pipeline. Original hard-coded Afaf_rich paths, OSC accounts, package installation commands and interactive/incomplete lines are retained. Review and adapt paths and dependencies before running. Do not run all variants sequentially.

The 16S denoising.sh parameters agree with saved QIIME2 DADA2 denoising artifacts. Exact lineage from the ITS/AMF script variants to the manuscript phyloseq objects has not yet been verified. No metagenomic scripts are included. See SCRIPT_MANIFEST.csv for origins and hashes.
